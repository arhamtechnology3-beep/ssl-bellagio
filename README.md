## 🌟 Overview
**SSL Bellagio** is an ultra-premium real estate landing portal and digital showcase presenting luxury 1 & 2 BHK smart homes, high-street retail, and commercial spaces located strategically opposite Sagaon Metro Station, Dombivli East.

Designed with an aesthetic inspired by Italian architecture, the official brand palette (Wine Red, Royal Gold, Tuscan Terracotta), and modern UI patterns from [21st.dev](https://21st.dev).

---

## ✨ Key Features & Capabilities

- **🎨 Royal Brand Theme:**
  - Official brand color harmony: Deep Wine (`#38040E`), Royal Gold (`#D4AF37`), Tuscan Terracotta (`#C85A32`), and Champagne accents.
  - Typography powered by *Cinzel Decorative* & *Outfit / Inter*.

- **📱 Authentic Mobile App Experience:**
  - **Native Mobile App Bar:** Sticky 56px header with live `● AI Living` pulse indicator and 1-tap call/WhatsApp triggers.
  - **Category Pills Strip:** Horizontally scrollable quick-navigation bar across all township zones.
  - **Connectivity Snap Carousel:** Touch-friendly snap carousel for transit highlights (1 Min Metro, 10 Mins Station East, Jupiter Hospital, Xperia Mall).
  - **Floating iOS/Android Dock:** 4-tab quick island at the bottom (Call, WhatsApp, Unlock Prices, Book Visit).
  - **Slide-up Bottom Sheet Modals:** Native bottom-sheet experience for appointment booking and brochure download with interactive drag handle.

- **🔒 Real Estate Lead Gating:**
  - Starting prices and high-res floor plans are locked by default (`₹ 4X.XX Lakhs*`).
  - Gated content automatically unlocks in real time upon valid lead submission.
  - Strict 10-digit Indian mobile validation ($[6\text{--}9]\times\times\times\times\times\times\times\times\times$) with input filtering and auto-clearing country codes.

- **📅 Interactive Site Visit Date Picker:**
  - Brand-themed date picker with quick date chips (`Today`, `Tomorrow`, `Saturday`, `Sunday`).
  - Real-time availability indicator (*"Site Open Daily with Free Cab Facility"*).

- **⚖️ Complete Legal & Regulatory Compliance:**
  - Dedicated [MahaRERA Sanction Approvals](rera-approvals.html) breakdown (sanction dates, approvals checklist, QR code).
  - Dedicated [Privacy Policy](privacy-policy.html) and [Terms & Conditions](terms-conditions.html) pages.

## 🚀 Getting Started

### Local Development
Run a local static HTTP server:

```bash
# Using Python
python3 -m http.server 8000

# Using Node.js (npx)
npx serve .
```

Open [http://localhost:8000](http://localhost:8000) in your browser.
